Noto 3D emoji renders in this directory

Source: https://github.com/googlefonts/noto-emoji, `3D/png/128` and `3D/png/512`.
Files are unmodified upstream `emoji_u<codepoint>.png` renders.

License: the upstream README states that "tools and most image resources are
under the Apache license, version 2.0", while the repository's own LICENSE file
(which is also reproduced here) carries the SIL Open Font License 1.1. The two
disagree; both permit redistribution with attribution, and the OFL's reserved-
name and no-sale clauses apply to the font rather than to images rendered from
it. Upstream was not asked to resolve it. Recorded here so the ambiguity is
visible rather than silently assumed.
